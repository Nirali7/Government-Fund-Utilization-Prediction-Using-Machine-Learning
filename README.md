# Government Fund Utilization Prediction Using Machine Learning

## 📌 Overview

Government Fund Utilization Prediction is a Machine Learning application that predicts whether government funds allocated to a scheme are likely to be utilized efficiently based on various input parameters.

The application provides a simple Streamlit interface for making predictions using a trained Machine Learning model.

---

## 🚀 Features

- Predict government fund utilization
- Interactive Streamlit web application
- Machine Learning based prediction
- User-friendly interface
- Fast real-time predictions

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Joblib

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Government-Fund-Utilization-Prediction-Using-Machine-Learning.git
```

Move to project folder

```bash
cd Government-Fund-Utilization-Prediction-Using-Machine-Learning
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```

---

## 📊 Machine Learning Model

- Classification Model
- Trained using Scikit-learn
- Encoders used for categorical features
- Real-time prediction through Streamlit
